# Quickstart: Module 4: Vision-Language-Action (VLA)

## Overview
This module introduces Vision-Language-Action (VLA) systems for connecting language, vision, and control in autonomous robots, focusing on voice-to-action flow and LLM-based robot planning.

## Chapter Structure
1. **Vision-Language-Action Overview**: Understanding VLA architecture and system integration
2. **Voice-to-Action**: Exploring the pipeline from speech to intent to ROS actions
3. **LLM-Based Planning**: Understanding task decomposition and multi-modal integration

## Learning Path
- Start with the [Specification](../../frontend/docs/module-4-vla/spec.md) to understand the module structure and learning objectives
- Proceed to Chapter 1 to understand the VLA architecture and system components: [Vision-Language-Action Overview](../../frontend/docs/module-4-vla/vision-language-action-overview.md)
- Proceed to Chapter 2 to learn about voice-to-action flow and ROS integration: [Voice-to-Action](../../frontend/docs/module-4-vla/voice-to-action.md)
- Complete with Chapter 3 to understand LLM-based planning and multi-modal integration: [LLM-Based Planning](../../frontend/docs/module-4-vla/llm-based-planning.md)
- Review the [Prompt History](../../frontend/docs/module-4-vla/prompt-history.md) for implementation details

## Prerequisites
- Basic understanding of robotics concepts
- Familiarity with AI and language models
- Knowledge of ROS (Robot Operating System) concepts (helpful but not required)
