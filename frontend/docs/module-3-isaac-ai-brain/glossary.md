# Glossary of Isaac Terms

## A

### Adaptive Monte Carlo Localization (AMCL)
A probabilistic algorithm for robot localization that uses particle filters to estimate the robot's pose in a known map.

## D

### Domain Randomization
A technique used in simulation to train models that can generalize to the real world by varying the simulation environment parameters.

## I

### Isaac Apps
Pre-built reference applications that demonstrate best practices in NVIDIA Isaac, including Isaac Manipulator and Isaac Carter.

### Isaac Lab
A framework for robot learning research that provides tools for reinforcement learning and physics simulation.

### Isaac Nucleus
An asset management and multi-robot orchestration service in the Isaac ecosystem.

### Isaac ROS
A collection of hardware-accelerated perception and navigation packages that run on NVIDIA Jetson platforms.

### Isaac Sim
A robotics simulation environment built on NVIDIA Omniverse that provides high-fidelity physics and sensor simulation.

## L

### LiDAR
Light Detection and Ranging - a remote sensing method that uses light in the form of a pulsed laser to measure distances.

## P

### Path Planning
The computational problem of finding a valid sequence of configurations to move from an initial configuration to a goal configuration.

## S

### SLAM (Simultaneous Localization and Mapping)
The computational problem of constructing or updating a map of an unknown environment while simultaneously keeping track of an agent's location within it.

### Sensor Fusion
The process of combining data from multiple sensors to create a more accurate and robust perception of the environment.

### Sim-to-Real Transfer
The process of transferring models trained in simulation to real-world robots.

## V

### Visual SLAM
SLAM that uses visual sensors (cameras) as the primary source of information for mapping and localization.

### Visual-Inertial Odometry
The process of estimating the pose of a camera by fusing visual information with data from an inertial measurement unit (IMU).
